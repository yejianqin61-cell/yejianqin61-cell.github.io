他马勒戈壁的这题踏马的我想了一早上，前缀和+哈希表。这个思想和思维模式我确实没见过，今天也算是学了新东西吧。

```cpp
#include <unordered_map>
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        unordered_map <int,int>mp;
        int size=nums.size();
        int ans=0;
        vector<int>pre(size+1,0);
        pre[0]=0;
        pre[1]=nums[0];
        int i=1;
        mp[0]=1;
        while(i<size+1){
            pre[i]=pre[i-1]+nums[i-1];
            int temp=mp[pre[i]-k];
            ans+=temp;
            mp[pre[i]]++;
            i++;
        }
        return ans;
    }
    
};
```

### 为什么不能用滑动窗口？

因为这题的区间和不是单调的，元素有可能是负数，tail++不一定保证会变大，head--不一定保证会变小，我说白了我白说了

### 那么要怎么做?

首先，我们创建一个前缀和数组pre。

在本题中，pre【i】的定义是，从第0个到第i-1个元素之和。

那么pre【0】=0.那么pre[1]=num[0];

那么递推公式就是pre[i]=pre[i-1]+nums[i-1];



然后,关键部分来了,要使用一个哈希表,来记录某个前缀和值出现的次数.这个需要的区间和有多少种合法的起点.因为同一个 `pre[i]`，可能对应多个满足条件的 `pre[j]`





然后是一个重要公式:sum(j,i)=k=pre[i+1]-pre[j];

这个时候,我们移项:pre[i+1]-k=pre[j];这就是关键公式了.

这表示,当我们走到了i+1这个地方,我想知道此前有没有前缀和是pre[j],这样子就可以通过相减,实现k的区间和.所以我们哈希表记录的就是这个pre[j]

所以这个while循环值得说道说道

```cpp
 while(i<size+1){
            pre[i]=pre[i-1]+nums[i-1];
            int temp=mp[pre[i]-k];
            ans+=temp;
            mp[pre[i]]++;
            i++;
        }
```

先查,然后再算,然后再记. 查->算->记

为什么?因为,要先算,才能找啊哈哈哈哈.

ans+=temp之后,再把这次新发现的前缀和放进map里,因为我们是一边查表,一边记录表.

### 那么至于一些边界条件,



#### 比如说while循环为什么是i<size+1而不是size,

因为前缀和数组比原数组多一个元素.

假设

nums = [1, 2, 3]
size = 3

那么

nums 值：   1   2   3

所以不难理解,因为size是nums的size.哈哈哈哈哈



#### 为什么mp[0]=1,

意思就是,因为pre[0]=0,好,所以mp[pre[0]]就是1了,因为已经存在一个pre[0]=0了,这个案例的存在,让mp[0]=1了.

等于我提前告诉我的哈希表,前缀和为0的情况我已经看过了,只有一种情况,因此mp[0]=1



#### 为什么最后才更新mp呢?

**主要针对k=0的时候的bug.**

一、假设我们先更新 mp，再查询

```
nums = [1]
k = 0
```

显然，答案应该是 `0`。

因为唯一的非空子数组 `[1]` 的和是 1，不是 0。

现在我们开始执行。

初始状态：

```cpp
pre[0] = 0;
mp[0] = 1;
ans = 0;
```

进入循环，`i = 1`：

```cpp
pre[1] = 1;
```

假设你先更新哈希表：

```cpp
mp[pre[1]]++;  // mp[1] = 1
```

再查询：

```cpp
ans += mp[pre[1] - k];
```

代入：

```cpp
ans += mp[1 - 0];
ans += mp[1];  // ans = 1
```

出 BUG 了！

算法认为找到一个和为 0 的子数组，但实际上根本没有。



##### 问题出在哪?

\[ pre[i]-pre[j]=k \]

其中，`pre[i]` 是当前前缀和，`pre[j]` 是历史前缀和。

我们有一个非常重要的条件：

\[ \boxed{0\le j<i} \]

为什么必须满足 `j < i`？

因为 `pre[i] - pre[j]` 对应的子数组是：

\[ nums[j],nums[j+1],\ldots,nums[i-1] \]

如果 `j = i` 呢？

\[ pre[i]-pre[i]=0 \]

这对应的是一个长度为 0 的空子数组！

而题目要求的是非空连续子数组，所以不能统计它。





**于是这题从找区间,变成了找点.通过哈希表记录,避免了O(n^2)复杂度的双重循环**

**是一种典型的使用额外空间优化时间复杂度的思想.**

```cpp
class Solution {
public:
    vector<int> findAnagrams(string s, string p) {
        vector<int> ans;
        int head=0;
        int size=s.length();
        int subsize=p.length();
        if(subsize>size)return ans;
        vector <int> window(26,0),need(26,0);
        for(int i=0;i<subsize;i++)need[p[i]-'a']++;

        for(int i=0;i<size;i++){
            window[s[i]-'a']++;
            if(i>=subsize)window[s[i-subsize]-'a']--;

            if(i>=subsize-1&&window==need){
                ans.push_back(i-subsize+1);
            }
        }
        return ans;
    }
};
```

然后这题用26位vector会比哈希表好点.

一个need,用来记录字串每个字符出现的次数,用作比较

```cpp
#include <unordered_map>
using namespace std;
class Solution {
public:
    unordered_map <string,int> mp;
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        int size=strs.size();
        vector<vector<string>> re;
        for(int i=0;i<size;i++){
            string temp=strs[i];
            sort(temp.begin(),temp.end());
            if(mp.count(temp)){
                re[mp[temp]].push_back(strs[i]);
            }else{
                vector<string>temping;
                temping.push_back(strs[i]);
                re.push_back(temping);
                mp[temp]=re.size()-1;
            }
        }
        return re;
    }
};
```

然后在哈希表中查,这个样式的string存在否?

不存在?那么直接创建一个vector<string>  用来存储这类的string,然后先pushback一个当下的strs[i],注意这个是没被sort过的.

然后再把这个temping给push进去答案数组.并且记录下角标,就是最后一位,因为是刚push进去的.用哈希表记录.



如果存在?ok啊,那么直接就可以push进去,用上哈希表中记录的角标,直接pushback.

```cpp
#include <unordered_map>
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        int left=0;
        int right=0;
        unordered_map<char,int> mp;
        int re=0;
            while(right<s.length()){
                if(mp.count(s[right])){
                    if(mp[s[right]]>=left){
                        left=mp[s[right]]+1;
                    }
                }
                mp[s[right]]=right;
                right++;
                re=max(re,right-left);
            }
        return re;
        
    }
};
```
