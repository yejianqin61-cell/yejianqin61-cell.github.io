## 1. 任务位置

- **Phase 1 可阅读的静态文章站**，目标是旧链接继续可打开。
- 本任务从文章日期和源文件路径生成页面。
- **前置**：内容集合。**后续**：入口页面。

## 2. 开发所需信息

**先读**

- `public` — 现有已生成的公开地址。
- `src/content.config.ts` — 文章集合的标识。
- `source/_posts` — 文件名与日期的关系。

**已确定**

- URL 格式保留为 `年/月/日/源文件路径/`。
- 日志的目录名属于 URL，不能扁平化。

**边界和接缝**

- 接触动态文章路由；不改变文章内容或主题入口。
- 接缝是 Astro 的静态路径生成。

**运行**

- `pnpm build`

**未知项**

- 文章日期必须可转为原有本地日期；否则停止并报告。

## 3. 工作流

1. 重述：每篇文章按旧地址生成静态页面。
2. 从源文件标识推导旧标题路径。
3. 从日期生成目录路径。
4. 实现全部静态路径与文章查找。
5. 构建并检查三个已知 URL。
6. 提交本任务。

## 4. 测试情形

| 情形 | 输入 | 预期 | 接缝 |
|---|---|---|---|
