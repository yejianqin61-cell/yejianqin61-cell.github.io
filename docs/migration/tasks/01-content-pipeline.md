## 1. 任务位置

- **Phase 1 可阅读的静态文章站**，目标是保留并呈现现有文章。
- 本任务建立 Astro 与 Markdown 内容集合。
- **前置**：无。**后续**：旧链接路由和页面模板。

## 2. 开发所需信息

**先读**

- `package.json` — 替换 Hexo 构建命令。
- `source/_posts` — 内容位置与 Frontmatter 形状。
- `source/images` — 必须保留的静态图片地址。

**已确定**

- 内容继续存放在现有 Markdown 文件中。
- 不引入 CMS、客户端框架或 CSS 依赖。

**边界和接缝**

- 接触构建与内容加载；不修改文章正文。
- 接缝是 Astro 的内容集合加载器。

**运行**

- `pnpm build`

**未知项**

- Frontmatter 日期格式必须由集合接受；若不兼容，停止并报告。

## 3. 工作流

1. 重述：让 Astro 直接读取原有文章。
2. 安装构建依赖并更新项目脚本。
3. 配置静态输出和公共图片目录。
4. 定义文章集合的字段与加载位置。
5. 运行构建，确认集合接受全部文章。
6. 提交本任务。

## 4. 测试情形

| 情形 | 输入 | 预期 | 接缝 |
|---|---|---|---|
| 全量文章 | 12 个 Markdown 文件 | 构建可读取 12 篇 | 内容集合 |
| 嵌套日志 | `日志/2026` 文件 | 文章保留源路径 | 内容集合 |
| 本地图片 | `/images/posts/...` | 构建输出同路径图片 | 静态目录 |
