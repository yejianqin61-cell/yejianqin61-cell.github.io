## 1. 任务位置

- **Phase 1 可阅读的静态文章站**，目标是读者能快速跳到文章段落与相关主题。
- 本任务把目录置于文章侧边，并从 Frontmatter 生成分类和标签页。
- **前置**：文章模板与内容集合。**后续**：最终交接。

## 2. 开发所需信息

**先读**

- `src/pages/[...article].astro` — 文章标题与目录数据。
- `src/content.config.ts` — 分类和标签字段。
- `source/_posts` — 现有 Frontmatter 分类方式。

**已确定**

- 桌面端目录固定在正文侧边；小屏幕回到正文前。
- 分类和标签页只用于进入文章，不增加搜索和标签云。

**边界和接缝**

- 接触文章模板、入口路由和样式；不修改 Markdown。
- 接缝是文章的 `headings`、`categories` 与 `tags`。

**运行**

- `pnpm build`，然后 `pnpm test`。

**未知项**

- 某篇文章可能没有标签；页面必须继续生成。

## 3. 工作流

1. 重述：目录和主题入口都必须服务于阅读。
2. 过滤文章二级标题，制作可滚动侧栏目录。
3. 给文章元信息接入分类与标签入口。
4. 生成分类和标签的静态文章清单。
5. 在窄屏下检查目录不会挤压正文。
6. 运行构建与校验。
7. 提交本任务。
