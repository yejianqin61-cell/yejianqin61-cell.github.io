## 1. 任务位置

- **Phase 1 可阅读的静态文章站**，目标是正文成为视觉中心。
- 本任务实现共享外壳与文章页。
- **前置**：内容集合与文章路由。**后续**：入口页面。

## 2. 开发所需信息

**先读**

- `source/_posts/日志/2026/11.2日志.md` — 长文、表格和代码的真实内容。
- `source/images` — 图片呈现范围。
- `src/pages` — 新页面路由。

**已确定**

- 正文列宽、字距和行距服务中文长读。
- 不加入侧栏、评论、打赏或文章摘要流。

**边界和接缝**

- 接触共享布局与文章模板；不增加交互框架。
- 接缝是渲染后的 Markdown 内容。

**运行**

- `pnpm build`

**未知项**

- 超宽表格与代码块必须水平滚动，不能压缩正文。

## 3. 工作流

1. 重述：文章正文要在桌面和手机上安静可读。
2. 制作含少量导航的页面外壳。
3. 制作标题、日期和文章元信息区。
4. 加入正文、图片、引用、代码和表格规则。
5. 加入相邻文章入口与深色主题。
6. 构建并检查长文 HTML。
7. 提交本任务。
