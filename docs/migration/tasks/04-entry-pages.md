## 1. 任务位置

- **Phase 1 可阅读的静态文章站**，目标是读者能安静进入文章。
- 本任务实现首页、索引与关于页。
- **前置**：内容集合与文章路径。**后续**：最终验证。

## 2. 开发所需信息

**先读**

- `source/about/index.md` — 关于页内容。
- `src/pages/[...route].astro` — 文章 URL 生成规则。
- `src/styles/global.css` — 共享视觉规则。

**已确定**

- 首页只显示站点介绍与文章清单。
- 索引按年份分组，不提供搜索与标签云。

**边界和接缝**

- 接触三个静态入口；不加分类或标签页面。
- 接缝是内容集合和文章 URL 工具。

**运行**

- `pnpm build`

**未知项**

- 关于页 Frontmatter 的 `type` 字段必须不影响渲染。

## 3. 工作流

1. 重述：入口页面只引导读者进入文章。
2. 制作首页的站点介绍与文章列表。
3. 制作按年份分组的完整索引。
4. 渲染现有关于页 Markdown。
5. 构建并检查首页、索引和关于页。
6. 提交本任务。
