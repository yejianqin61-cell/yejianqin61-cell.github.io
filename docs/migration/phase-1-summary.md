## 2. 这意味着什么

站点现在是一个文章优先的静态站，而不是依赖 Hexo 主题的博客。文章仍由现有 Markdown
驱动，现有图片 URL 和日期式 URL 都保留。页面在桌面与手机中以正文宽度、行距和排版为中心。
