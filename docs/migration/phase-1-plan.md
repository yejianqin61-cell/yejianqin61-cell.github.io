# 文章站重建计划

状态：2026-11-07

## 1. 需求

- **R-1 保留文章与旧链接** — 用户要求开始重构；现有公开链接不能失效。
- **R-2 把阅读页作为主界面** — 用户明确要求注重文字体验。
- **R-3 提供安静的入口** — 首页、文章索引、分类、标签与关于页只帮助进入文章。
- **R-4 继续静态发布** — 当前站点使用 GitHub Pages；不增加服务端。

## 2. 方案

### R-1 保留文章与旧链接

- **方案**：直接读取现有 Markdown 与图片目录，并按原日期和源文件路径生成文章地址。
- **触及**：内容加载与静态资源。
- **测试点**：生产构建后的文章 HTML 地址。
- **验收**：12 篇文章可生成；3 个已知旧地址存在；图片地址不变。
- **难点**：日志文章的源文件位于嵌套目录。

### R-2 把阅读页作为主界面

- **方案**：用一套共享页面外壳和文章模板承载排版、目录、代码、引文与深浅主题。
- **触及**：页面组件与样式。
- **测试点**：文章 HTML 与浏览器渲染。
- **验收**：标题、日期、正文、标题锚点和相邻文章都可阅读。
- **难点**：中文长文、表格和代码块必须在窄屏中保持可读。

### R-3 提供安静的入口

- **方案**：做首页、完整文章索引、分类、标签与关于页。
- **触及**：静态路由与文章元数据。
- **测试点**：生产构建后的入口链接。
- **验收**：分类和标签都能到达文章；首页不显示摘要流或侧栏。
- **难点**：索引要帮助找到文章，不能变回博客仪表盘。

### R-4 继续静态发布

- **方案**：以 Astro 输出静态目录，并让现有发布仓库可直接使用构建结果。
- **触及**：项目脚本与部署说明。
- **测试点**：`pnpm build`。
- **验收**：构建成功；不依赖运行时服务器。
- **难点**：现有 Hexo 依赖不能同时控制构建。

## 3. Phase 1 — 可阅读的静态文章站

**覆盖**：R-1 保留文章与旧链接、R-2 把阅读页作为主界面、R-3 提供安静的入口、R-4 继续静态发布。

**目标**：访客能从首页进入一篇舒适排版的文章，并打开所有旧文章链接。

**任务**

- 建立 Astro 静态构建和现有 Markdown 内容集合
- 生成兼容旧地址的文章路由并检查内容输出
- 制作文章优先的共享页面外壳和正文排版
- 制作首页、文章索引和关于页，并接入文章数据
- 在文章侧边提供目录，并生成分类和标签入口
- 验证构建、旧链接和移动端阅读宽度

**证明**：生产构建完成，12 篇文章与三个入口页面均存在。

**不在本阶段**：搜索、评论、RSS、后台、CMS 与站内数据统计。
